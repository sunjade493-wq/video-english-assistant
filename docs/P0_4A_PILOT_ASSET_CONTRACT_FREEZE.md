# P0-4A Pilot Asset Contract Freeze

Status: FROZEN

Freeze Date: 2026-06-22

Milestone: P0-4A — AI-assisted Analyze Pipeline Pilot

## Purpose

Freeze the asset scope and data boundaries for the P0-4A pilot implementation.

This contract defines exactly:

* which assets may be processed;
* which files may be read;
* which files may be generated;
* which files must remain untouched;
* where the pilot implementation must stop.

This contract exists to prevent scope expansion and accidental modification of Runtime or production data.

---

## Pilot Scope

Pilot processing scope:

```text
00:00:00
~
00:02:00
```

Only the first two minutes of the episode may be processed.

The pilot must not process the entire episode.

The pilot must not process other episodes.

## Explicit Non-Goals

P0-4A must NOT:

* process the full episode;
* process other episodes;
* generate coordinates;
* generate marker positions;
* call Qwen-VL;
* perform OCR;
* generate visual mappings;
* modify Runtime files;
* modify script.js;
* modify styles.css;
* modify existing obstacle JSON;
* modify existing subtitle JSON;
* generate Marker rendering logic.

These responsibilities belong to later milestones:

```text
P0-4B
Qwen Coordinate Extraction Pilot

↓

P0-4C
Runtime Marker Rendering Pilot
```
