# V2.7B Actual Qwen/OpenAI-Compatible Episode Pipeline

Status: Implemented for human review. V2.7B is **not frozen**.

## Goal

V2.7B adds the first real AI episode production path:

```text
real .srt subtitle input
↓
OpenAI-compatible AI provider call
↓
vocabulary obstacles
↓
comprehension obstacles using V2.6E gold-standard fields
↓
frozen episode obstacles JSON
↓
runtime reads generated JSON only
```

The provider is intentionally neutral. The code does not hardcode OpenAI, Qwen, DashScope, or any API key.

## Required environment variables

Set these variables in the shell or CI secret store before running generation:

```bash
export AI_BASE_URL="https://dashscope.aliyuncs.com/compatible-mode/v1"
export AI_API_KEY="<your-provider-api-key>"
export AI_MODEL="qwen-plus"
```

The current production provider may be Qwen/DashScope, but the implementation only assumes an OpenAI-compatible `/chat/completions` endpoint.

## Qwen / DashScope example

```bash
AI_BASE_URL="https://dashscope.aliyuncs.com/compatible-mode/v1" \
AI_API_KEY="$AI_API_KEY" \
AI_MODEL="qwen-plus" \
node generate-obstacles.js
```

Use the model configured for the repository secrets if it differs from `qwen-plus`.

## Exact command to run

```bash
node generate-obstacles.js --input sample-subtitle.srt --output sample-obstacles.json
```

Default paths are the same, so this shorter command is equivalent:

```bash
node generate-obstacles.js
```

## Output path

The generated episode obstacle file is written to:

```text
sample-obstacles.json
```

The file includes:

- `metadata`
- `subtitleRecords`
- `rawAIObstaclePayload`
- `normalizedObstacles`
- `generatedByAI: true`
- schema/version information
- verification notes

## Runtime rule

Runtime playback must not call AI.

The web runtime reads `sample-obstacles.json` and renders the generated frozen obstacle data. AI calls happen only in the production script (`generate-obstacles.js`) before episode playback/release.

## Human review requirement

V2.7B output is generated for review. Do not declare V2.7B frozen until a human reviewer approves the generated vocabulary and comprehension obstacle cards.
