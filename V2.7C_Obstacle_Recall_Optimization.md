# V2.7C Obstacle Recall Optimization

Status: Frozen ✅

## Goal

Improve comprehension obstacle recall in the real AI episode pipeline without turning the detector into a “mark everything” system.

V2.7B proved the pipeline:

```text
Real subtitle
↓
Qwen/OpenAI-compatible AI
↓
sample-obstacles.json
↓
runtime reads generated JSON
```

Human review found the AI output was too conservative: it detected `No worries`, `clear my head`, and `bottle it up`, but missed useful learner-value expressions such as `saved me a seat`, `grab coffee`, and `threw me off`.

## Core Principle

The goal is not to mark every phrase. The goal is to avoid missing valid comprehension obstacles that Chinese learners are likely to misunderstand even when the individual words look simple.

Recall is preferred over excessive minimalism, but over-tagging remains forbidden.

## Valid Comprehension Obstacle Criteria

The V2.7C prompt explicitly targets expressions matching at least one of these criteria:

1. Fixed expression.
2. Phrasal verb.
3. Idiom.
4. Slang.
5. Spoken conversational chunk.
6. Multi-meaning simple expression.
7. Context-dependent expression.
8. Literal meaning differs from actual meaning.
9. Common Chinese-learner confusion pattern.

## Negative Rules

The prompt explicitly rejects:

- Transparent literal phrases.
- Ordinary grammar structures.
- Ordinary verb + object combinations.
- Phrases whose meaning can be understood directly from the words.
- Every noun phrase.
- Every adjective phrase.

Examples such as `open the door`, `drink some water`, `go home`, `read the book`, and `sit down` should not be marked unless context changes their meaning.

## Same Subtitle Rule

If a subtitle contains multiple valid comprehension obstacles, the generated JSON must keep all of them. The model must not arbitrarily choose only one obstacle from a subtitle.

## Prompt Changes

`generate-obstacles.js` now builds a prompt that requires the AI to:

- Scan every subtitle line.
- Detect fixed expressions.
- Detect phrasal verbs.
- Detect conversational chunks.
- Detect multi-meaning expressions.
- Detect context-dependent expressions.
- Preserve subtitle order.
- Preserve multiple obstacles in one subtitle.
- Not skip expressions merely because the words are simple.
- Prioritize learner value.
- Avoid expressions that are fully transparent and provide no learning value.

## V2.6E Card Format

The V2.6E card format remains unchanged:

```text
Expression

字面意思：

实际意思：

固定用法：

表示：
```

The generated cards must not add:

- Grammar Explanation.
- Usage Notes.
- Example Sentences.

## Runtime Boundary

Runtime still never calls AI. AI generation is an offline content-production step. The application runtime reads frozen obstacle JSON only.

No UI redesign was made. V2.7C does not change Timeline, Learning Tips, Progress, Bottom Sheet, or Video Layout.

## Recall Fixture

The V2.7C validation fixture uses the V2.7B sample subtitle set:

```text
I almost missed the train this morning, but Maya saved me a seat.
No worries, we still have time to grab coffee before the meeting.
Actually, can we skip it? I need to clear my head for a minute.
Sure, but don't bottle it up if something is bothering you.
Thanks. I just got a weird message from the landlord, and it threw me off.
```

Expected candidate obstacle set:

- No worries
- clear my head
- bottle it up
- threw me off
- saved me a seat
- grab coffee
